Baca APK / ZIP

Tempel/pilih file APK, APKS, atau ZIP project hasil decompile. PUTRA PRO akan mencoba membaca package name dan struktur file secara lokal di perangkat.

Belum ada file dianalisis.
Hasil analisis akan muncul di sini.
Jadikan aplikasi tanpa watermark builder: watermark “HTML to APK Builder” biasanya ditambahkan oleh aplikasi pembungkus yang dipakai, bukan oleh file HTML ini. Untuk APK tanpa watermark, buat project Android milik sendiri (misalnya Sketchware Pro), masukkan HTML ini ke folder assets, tampilkan dengan WebView, aktifkan JavaScript, lalu build dan sign APK sendiri. Jika memakai builder pihak ketiga, gunakan opsi resmi/no-watermark atau lisensi resminya; jangan mengubah watermark milik aplikasi lain secara paksa.
Batasan: Pembacaan dilakukan di browser, tanpa upload ke server. APK/APKS dapat dibaca untuk mengambil manifest dan package name, tetapi APK terkompilasi berisi DEX, bukan file Smali. Untuk menyisipkan Smali, gunakan ZIP project yang sudah didecompile (berisi folder smali*/). PUTRA PRO tidak menjamin semua APK mendukung patch; jika manifest/arsip rusak, terenkripsi, atau formatnya tidak didukung, hasil akan ditandai gagal dan tidak memaksakan patch.
